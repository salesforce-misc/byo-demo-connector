# Open CTI Migration: Dreamforce Session Resources
Open CTI is in maintenance mode and is scheduled for retirement in February 2028. Salesforce recommends migrating Open CTI integrations to Salesforce Voice.
## Essential Resources
1. [Open CTI retirement knowledge article](https://help.salesforce.com/s/articleView?id=005306437&type=1)  
   Customer-facing information about Open CTI maintenance mode and retirement.
2. [Migrate from Open CTI learning map](https://help.salesforce.com/s/articleView?id=service.cti_migrate_map.htm)  
   The starting point for admins, architects, partners, and decision-makers planning a migration.
3. [Open CTI to Salesforce Voice developer migration guide](https://developer.salesforce.com/docs/service/api-cti/guide/migrate-cti.html)  
   The central technical migration guide for partners and independent software vendors.
4. [Compare Open CTI and Salesforce Voice conceptual models](https://developer.salesforce.com/docs/service/api-cti/guide/compare-opencti-voice.html)  
   Explains the architectural shift, including Task to VoiceCall, Omni-Channel ownership, and connector events.
5. [Open CTI migration planning checklist](https://developer.salesforce.com/docs/service/api-cti/guide/plan-cti-migration.html)  
   Covers assessment, implementation, flow configuration, and validation phases.
6. [Salesforce Voice with Partner Telephony Developer Guide](https://developer.salesforce.com/docs/atlas.en-us.voice_pt_developer_guide.meta/voice_pt_developer_guide/voice_pt_intro.htm)  
   The main technical reference for building a replacement telephony integration.
7. [BYO demo connector](https://github.com/salesforce-misc/byo-demo-connector)  
   A working Salesforce Voice connector that developers can clone instead of starting from scratch.
8. [Salesforce Voice with Partner Telephony quickstart](https://github.com/salesforce/scv-partner-telephony-quickstart)  
   A sample application and Salesforce metadata for configuring a development org.
9. [Service Connector API reference](https://developer.salesforce.com/docs/service/service-connector-api/overview)  
   Reference documentation for connector methods, events, capabilities, and SDK contracts.
10. [Voice Toolkit API component reference](https://developer.salesforce.com/docs/component-library/bundle/lightning-service-cloud-voice-toolkit-api/documentation)  
    Provides Lightning Web Components with access to Salesforce Voice call controls and real-time telephony events.
11. [Lightning Message Service](https://developer.salesforce.com/docs/platform/lwc/guide/use-message-channel.html)  
    Enables communication between Voice Extensions and components elsewhere in the Lightning application, including through the standard `ServiceCloudVoiceMessageChannel__c` channel.
